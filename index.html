webDS

Front-end to run a melonDS WebAssembly build. You must provide the built emulator and any BIOS/ROM files.

How to use

  1. Build melonDS to WebAssembly (see README) and place the generated files in static/emu/. Required files: melonDS.js, melonDS.wasm (names depend on your Emscripten build output).
  2. Open this page served from a local server (do not use file://). Use npm run serve to start a dev server.
  3. Load a .nds ROM and any BIOS files you have dumped from your own hardware. Click Start.

Legal: This project does not include any BIOS, firmware, or commercial ROMs. Do not download copyrighted BIOS/ROMs from the internet.
